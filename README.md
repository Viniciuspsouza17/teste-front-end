
# Teste Front-End Jr — Econverse

Projeto desenvolvido para o processo seletivo de Desenvolvedor Front-End Jr da Econverse.

## Tecnologias utilizadas

- React
- TypeScript
- Vite
- Sass (SCSS)
- Lucide React

## Funcionalidades

- Página de e-commerce baseada no Figma da Econverse
- Listagem de produtos carregados de um arquivo JSON
- Modal com informações do produto selecionado
- Componentes reutilizáveis
- Layout responsivo

## Como executar o projeto

### 1. Instalar as dependências

```bash
npm install --legacy-peer-deps
```

### 2. Iniciar o projeto

```bash
npm run dev
```

Acesse o endereço exibido no terminal, normalmente http://localhost:5173/.

### 3. Gerar a versão de produção

```bash
npm run build
```

### 4. Visualizar a versão de produção

```bash
npm run preview
```

**Observação:** no PowerShell do Windows, caso o comando `npm` seja bloqueado, utilize `npm.cmd`.

## Organização

Os componentes estão organizados em `src/components`, e os produtos são carregados de `public/products.json`.
